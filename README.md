# 全自动广告系统 v1.0

## 项目简介

全自动广告系统是一个基于PyQt5开发的智能广告管理工具，提供广告创建、编辑、批量处理、数据分析等功能。

## 主要特性

### 🚀 核心功能
- ✅ 广告数据的增删改查
- ✅ 智能去重机制
- ✅ 多线程批量处理
- ✅ 实时数据缓存
- ✅ 数据导入导出
- ✅ 深度分析与优化

### 🧠 智能特性
- ✅ 深度思考分析
- ✅ 逻辑推理优化
- ✅ 自动反思修复
- ✅ 缺失数据补全
- ✅ 逻辑错误检测

### 💾 数据管理
- ✅ SQLite数据库存储
- ✅ JSON格式缓存
- ✅ 自动数据备份
- ✅ 数据完整性检查

## 功能使用指南

### 1. 广告管理
- **添加广告**: 在左侧编辑面板填写信息，点击"添加广告"
- **编辑广告**: 从右侧列表选择广告，修改后点击"更新广告"
- **删除广告**: 点击列表中的"删除"按钮
- **搜索广告**: 在搜索框中输入关键词过滤

### 2. 批量处理
- **智能优化**: 点击"批量处理广告"进行深度分析
- **多线程加速**: 自动使用多线程提升处理速度
- **进度监控**: 实时显示处理进度

### 3. 数据管理
- **导出数据**: 文件 → 另存为 → 选择保存位置
- **导入数据**: 文件 → 导入数据 → 选择JSON文件
- **清理缓存**: 工具 → 清理缓存
- **数据统计**: 工具 → 数据统计

### 4. 高级功能
- **自动去重**: 系统自动检测并阻止重复广告
- **智能补全**: 自动补充缺失的广告信息
- **逻辑修复**: 自动检测并修复数据逻辑错误
- **预算优化**: 基于目标受众智能调整预算

## 故障排除

### 常见问题

**Q: 程序启动失败**
A: 检查Python版本和依赖包是否正确安装

**Q: 数据库连接错误**
A: 确保data目录存在且有写权限

**Q: 界面显示异常**
A: 尝试更新PyQt5到最新版本

**Q: 处理速度慢**
A: 在配置文件中增加worker线程数

### 日志文件
- 位置: `logs/app.log`
- 级别: DEBUG, INFO, WARNING, ERROR
- 自动轮转: 每天一个文件

### 数据恢复
1. 检查`data/ads.db.backup`备份文件
2. 从导出的JSON文件恢复
3. 联系技术支持
