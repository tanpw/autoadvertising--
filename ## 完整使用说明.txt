## 完整使用说明

### 1. 安装步骤

1. **下载项目文件**
   - 将所有文件保存到一个文件夹中
   - 保持文件结构完整

2. **安装Python环境**
   ```bash
   # 推荐使用Python 3.8或更高版本
   python --version
   ```

3. **安装依赖包**
   ```bash
   pip install -r requirements.txt
   ```

4. **运行程序**
   ```bash
   # 方法1: 直接运行
   python main.py
   
   # 方法2: 使用启动器
   python run.py
   ```

### 2. 功能详解

#### 广告管理
- **创建**: 填写表单 → 点击"添加广告"
- **编辑**: 选择列表项 → 修改表单 → 点击"更新广告"
- **删除**: 点击列表中的"删除"按钮
- **搜索**: 在搜索框输入关键词

#### 智能处理
- **去重机制**: 自动检测内容相似度，防止重复
- **深度分析**: 分析关键词密度、内容质量
- **逻辑推理**: 根据受众优化预算分配
- **自动修复**: 检测并修复数据错误

#### 数据导入导出
- **导出**: 文件 → 另存为 → JSON格式
- **导入**: 文件 → 导入数据 → 选择JSON文件
- **备份**: 自动创建数据库备份

### 3. 高级配置

#### 性能调优
```json
{
  "processing": {
    "max_workers": 8, // 增加线程数
    "batch_size": 50, // 调整批处理大小
    "timeout": 60 // 增加超时时间
  }
}
```

#### 缓存优化
```json
{
  "cache": {
    "max_size": 52428800, // 50MB缓存
    "ttl": 43200 // 12小时过期
  }
}
```

### 4. 故障排除

#### 常见错误及解决方案

1. **ModuleNotFoundError: No module named 'PyQt5'**
   ```bash
   pip install PyQt5
   ```

2. **数据库锁定错误**
   - 关闭所有程序实例
   - 删除`data/ads.db-wal`和`data/ads.db-shm`文件

3. **界面显示不正常**
   - 尝试不同的主题: 编辑配置文件中的theme设置
   - 检查系统DPI设置

4. **处理速度慢**
   - 减少max_workers数量
   - 清理缓存文件
   - 增加系统内存
